# React + TypeScript Example

This example demonstrates ESLint configuration for a React + TypeScript project.

## Auto-Detection

The config automatically detects:
- ✅ Framework: **React** (from `react` dependency)
- ✅ Environment: **browser** (default for React)
- ✅ TypeScript: **Yes** (from `tsconfig.json`)

## Setup

```bash
npm install
npm run lint
```

## Features

- React 18 with new JSX transform
- TypeScript with strict mode
- ESLint with React Hooks rules
- Zero configuration required
