# Astro + TypeScript Example

This example demonstrates ESLint configuration for an Astro + TypeScript project.

## Auto-Detection

The config automatically detects:
- ✅ Framework: **Astro** (from `astro` dependency)
- ✅ Environment: **universal** (browser + node for island architecture)
- ✅ TypeScript: **Yes** (from `tsconfig.json`)

## Setup

```bash
npm install
npm run lint
```

## Features

- Astro with island architecture
- TypeScript with strict mode
- ESLint with Astro-specific rules
- Universal environment support (client + server)
- Built-in accessibility rules
- Zero configuration required
