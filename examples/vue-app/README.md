# Vue 3 Example

This example demonstrates ESLint configuration for a Vue 3 project.

## Auto-Detection

The config automatically detects:
- ✅ Framework: **Vue** (from `vue` dependency)
- ✅ Environment: **browser** (default for Vue)
- ✅ TypeScript: **No** (no tsconfig.json)

## Setup

```bash
npm install
npm run lint
```

## Features

- Vue 3 Composition API
- `<script setup>` syntax
- ESLint with Vue-specific rules
- Zero configuration required
