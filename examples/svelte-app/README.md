# Svelte 5 Example

This example demonstrates ESLint configuration for a Svelte 5 project with runes.

## Auto-Detection

The config automatically detects:
- ✅ Framework: **Svelte** (from `svelte` dependency)
- ✅ Environment: **browser** (default for Svelte)
- ✅ TypeScript: **No** (no tsconfig.json)

## Setup

```bash
npm install
npm run lint
```

## Features

- Svelte 5 with runes ($state, $derived, etc.)
- ESLint with Svelte-specific rules
- Accessibility checks
- Zero configuration required
