# Solid.js + TypeScript Example

This example demonstrates ESLint configuration for a Solid.js + TypeScript project.

## Auto-Detection

The config automatically detects:
- ✅ Framework: **Solid.js** (from `solid-js` dependency)
- ✅ Environment: **browser** (default for Solid.js)
- ✅ TypeScript: **Yes** (from `tsconfig.json`)

## Setup

```bash
npm install
npm run lint
```

## Features

- Solid.js with reactive primitives (signals, effects, memos)
- TypeScript with strict mode
- ESLint with Solid-specific reactivity rules
- Signal/Store pattern validation
- Zero configuration required
